# ItiOptimiser

Unity 2022.3用のVRChatアバター軽量化ツールです。

Unityの `Tools > ItiOptimiser` から開きます。候補を確認して適用する画面と、
選択したアバターの変更履歴を表示する画面があります。変更前の `.meta` は二重のmanifestと
ともにバックアップされ、履歴画面から復元できます。

テクスチャアトラスは、アバターを選択して
`Tools > ItiOptimiser > 選択中のアバターにテクスチャアトラス化を追加` を実行します。
最初は「保守的」を使用し、ビルド後の見た目を確認してください。

内部package IDとnamespaceには、既存シーンとの互換性のため旧識別子が残っています。
詳しい仕様と既知の制約はリポジトリの `README.md` と `docs/spec.md` を参照してください。
